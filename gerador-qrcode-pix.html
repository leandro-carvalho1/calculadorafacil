Perguntas frequentes

O QR Code PIX gerado aqui é seguro?

Sim. O QR Code é gerado inteiramente no seu navegador usando o padrão oficial do Banco Central (BR Code). Nenhum dado é enviado para servidores externos. Você pode verificar isso observando que o QR Code aparece mesmo sem conexão com a internet após carregado.

Qual a diferença entre QR Code com e sem valor?

QR Code sem valor definido permite que o pagador digite o valor que quiser — ideal para cobranças variáveis. QR Code com valor fixo já vem preenchido com o montante, facilitando pagamentos de valor específico como produtos ou serviços com preço definido.

Posso usar esse QR Code para cobrar clientes?

Sim, desde que a chave PIX seja válida e esteja cadastrada no seu banco. O QR Code segue o padrão EMV do Banco Central e é aceito por todos os bancos e fintechs que operam o PIX no Brasil.

O QR Code tem prazo de validade?

QR Codes estáticos (gerados aqui) não têm prazo de validade — funcionam indefinidamente enquanto a chave PIX estiver ativa. QR Codes dinâmicos (gerados pelos bancos com data de vencimento) são diferentes e precisam ser gerados pelo sistema bancário.

Como faço para colocar o QR Code no meu site ou cartão?

Clique em "Baixar PNG" para salvar a imagem. Você pode inserir essa imagem em qualquer material — site, cardápio, cartão de visita, banner ou nota fiscal. Basta usar o arquivo PNG como uma imagem comum.
